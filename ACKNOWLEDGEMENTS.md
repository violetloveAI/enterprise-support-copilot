# Acknowledgements

This project implements an original synthetic expense-support domain and does not copy a
reference application's prompts, data model, user interface, test data, or deployment code.
It was informed by these open-source projects and documentation:

- [LangChain RAG Research Agent Template](https://github.com/langchain-ai/rag-research-agent-template)
  (MIT): separation of indexing and retrieval concerns, document metadata, and graph-oriented RAG.
- [LangGraph](https://github.com/langchain-ai/langgraph) and its customer-support learning material
  (MIT): explicit state, conditional routing, tool nodes, persistence, interrupts, and resume commands.
- [Red Hat IT Self-Service Agent](https://github.com/rh-ai-quickstart/it-self-service-agent)
  (MIT): enterprise self-service product framing, mock integrations, evaluation, tracing, and guardrails.

See each linked project for its copyright notices and full license.
