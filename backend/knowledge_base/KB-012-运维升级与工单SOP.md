# 运维升级与工单 SOP

## 风险分级

- 低：有明确手册步骤、无数据或财务影响、用户可自行处理。
- 中：需要权限、主数据或财务配置人员处理；单笔单据受阻。
- 高：批量影响、接口认证故障、重复过账风险、月结影响或证据互相冲突。

## 必须升级

账号或权限变更、主数据修复、审批待办转派、财务配置变更、接口连续失败三次、无日志但状态异常、可能重复记账或任何写操作都必须升级人工。

## 工单内容

工单应包含用户编号、报销单号、问题分类、风险等级、实际查询证据、知识依据和已执行步骤。不得记录 API Key、访问令牌、完整身份证号、银行卡号或模型隐藏推理。创建工单是写操作，必须由用户明确批准后执行。
