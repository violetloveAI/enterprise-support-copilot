# 报销角色权限矩阵

## 角色

| 角色 | 能力 |
|---|---|
| `EMPLOYEE` | 查看本人报销单和个人主数据 |
| `CLAIM_SUBMITTER_C100` | 提交 C100 公司代码普通报销 |
| `CLAIM_SUBMITTER_C200` | 提交 C200 公司代码普通报销 |
| `TRAVEL_CLAIM` | 创建和提交差旅报销 |
| `LINE_MANAGER` | 审批直属员工报销 |
| `FINANCE_REVIEWER` | 财务合规复核 |

权限诊断必须使用用户编号，不能只用中文姓名。缺少权限、范围不匹配或账号锁定均需由人工权限管理员处理。
