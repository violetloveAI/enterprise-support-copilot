# 凭证生成规则

## 生成前提

报销单业务审批完成后进入凭证队列。系统根据公司代码、费用项目、税码和成本对象映射借贷科目。凭证状态为 `POSTED` 表示已经写入财务系统；`FAILED` 必须结合错误码排查。

## 常见错误

- `FI_PERIOD_CLOSED`：过账日期所在财务期间未开放。
- `GL_ACCOUNT_MISSING`：费用项目没有有效的总账科目映射。
- `TAX_CODE_INVALID`：税码与公司代码或发票类型不兼容。
- `COST_OBJECT_INVALID`：成本中心或项目已失效。

禁止通过反复重试绕过期间或配置错误。配置修复后应由授权财务人员重新触发凭证生成。
