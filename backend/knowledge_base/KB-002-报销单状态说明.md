# 报销单状态说明

## 常见状态

- `DRAFT`：尚未提交，可以由申请人编辑。
- `SUBMIT_FAILED`：提交前校验或权限校验失败，应读取页面提示。
- `IN_APPROVAL`：审批中，需要结合审批流判断当前节点。
- `APPROVED`：业务审批完成，等待财务凭证或付款处理。
- `VALIDATION_FAILED`：主数据或字段校验未通过。
- `INTERFACE_ERROR`：跨系统传输失败，需要查询接口日志。
- `PAID`：付款完成。
- `REJECTED`：审批人已驳回，应查看驳回意见后修改或重新发起。

状态更新时间超过两个工作日且没有待办人或明确错误码时，应升级人工支持。
